# Public status is Open or Closed

Trading ends when the oracle reports, which is earlier than when the liquidity provider withdraws the pool. Public pages therefore use two words: Open, and Closed once the oracle has reported. Resolved stays on the liquidity page, and only when that withdrawal is known. A missing withdrawal log leaves the public page Closed. A third public word would split one trading state in two, and guessing Resolved would say the pool is gone while redeem is still open.
