# Which retro and builder grants fit a solo dev

Label: wayfinder:research
Type: research
Status: closed

## Question

Which retro and builder grant programs could pay a solo, possibly anonymous developer for a creator-market prediction app on Base (a Farcaster / Base App mini app), and what does each require?

Cover, for each program open or recurring as of late 2026:

- Base Builder Grants (retroactive, nominated), Base or Talent Protocol builder rewards, Optimism Retro Funding (onchain builders rounds), and grants from Pyth, Chainlink, Coinbase Developer Platform or Telegram/TON. Add any other program that pays retroactively for shipped onchain apps.
- Eligibility: shipped product or idea, mainnet or testnet, identity or KYC, team size, whether gambling or prediction markets are excluded.
- What usage they measure (transactions, unique wallets, gas, retention) and any published thresholds or past winners of similar size.
- Payout size, how often it pays, and how long from shipping to payout.
- Whether real-money prediction markets are excluded, and whether sponsored-gas activity counts or is filtered as farming.

Required output: a table ranked by expected payout per hour of work for a solo dev, with sources, and a named first pick.

## Resolution

First pick: **Base Builder Grant Program** (announced 2026-08-10; up to $5,000 plus GTM/product support; prediction markets are its first listed focus area; needs a live product, Builder Code integration and a form; "very selective"). Ruled out: Optimism Retro Funding (paused 12+ months), Talent/Base Builder Rewards (wound down), Chainlink Build (now paid commercial deals), TON (needs the TON chain). Base Builder Codes rewards are only "potential". No program publishes usage thresholds, a sponsored-gas rule or a farming filter. Older Base retro grants required W8/W9 forms, so full anonymity is unlikely. No real-money prediction-market exclusion found. The Base X announcement and OP Atlas banner couldn't be loaded.
